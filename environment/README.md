# Environment capture

The exact 2024 computational environment has not been recovered from the surviving private archive.

The public upstream FlareML README states that its own environment was tested on Python 3.9.13 and lists historical versions including NumPy 1.19.5, scikit-learn 0.24.2, pandas 1.4.4, SciPy 1.6.3 and matplotlib 3.5.2. Those versions describe the upstream FlareML project, not necessarily the exact environment used for every MSc experiment.

A corrected post-MSc rerun should create its own locked environment file only after the new pipeline has been executed and verified. That environment should be labelled as a **new reconstruction environment**, not as a recovered 2024 environment.
