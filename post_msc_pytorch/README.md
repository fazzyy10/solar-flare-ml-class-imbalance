# Post-MSc PyTorch continuation

Fawaz later returned independently to the solar-flare classification problem using PyTorch. This work is **post-MSc, self-directed and unpublished**.

It is not part of the submitted 2024 dissertation and must never be blended into the historical MSc results.

Detailed code and numerical results are not published in this repository yet because the underlying source artefacts have not been fully reconciled against the private archive.
